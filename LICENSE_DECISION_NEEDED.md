# License Decision Needed

A real open-source license must be chosen before public release of this repository.

Common choices for computational biology repositories include:

- MIT
- BSD-3-Clause
- GPL-3.0

The final license choice should not be made silently in the repository packaging process. It requires approval from the PI, institution, project stakeholders, and any applicable funding or collaboration agreements.

Until a final license is selected, `LICENSE_PLACEHOLDER.txt` is retained at the repository root and `CITATION.cff` marks the license field as `TO_BE_DECIDED`.

Recommended next step: confirm the intended license with the PI/institution, then replace `LICENSE_PLACEHOLDER.txt` with a real `LICENSE` file and update `CITATION.cff`.
