# Utilities

Shared utilities not tied to a manuscript-output entry point may be placed here. The operative figure-generation implementation formerly distributed as `v5_helpers.R` is now intentionally kept with Layer 2 under `scripts/active_manuscript/lib/figure_helpers_v6.R`.

Historical local-root utilities (`project_tree.R` and `temporal_code.R`) are excluded from this public branch because they are not invoked by `run_all_manuscript_outputs_v6.R`. Portable Layer 2 execution uses the repository-contained scripts under `scripts/active_manuscript/`.
