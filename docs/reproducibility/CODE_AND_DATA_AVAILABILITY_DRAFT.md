# Code and Data Availability Draft

## A. Repository Release Candidate Statement

Analysis code for the frozen, transfer-oriented IMRS scoring framework, reviewer-facing manuscript-output reproduction layer, retained-gene enrichment analysis, supplementary table generation, and reproducibility documentation is available at <https://github.com/YanshengLuo/InnateImmuneResponseScore>.

The release includes staged derived inputs required by the Layer 2 reviewer-facing runner, manuscript figure-generation inputs, retained-gene enrichment source inputs, and Supplementary Tables S1-S5 source inputs. NAR G&B readiness materials are retained as optional internal documentation rather than a required default output. The default runner starts from staged derived inputs and does not run raw-data retrieval, full framework reconstruction, frozen-gene reconstruction, HiPerGator/SLURM jobs, or archive/legacy scripts.

## B. Publication Statement Candidate

Analysis code and reproducibility materials for the IMRS manuscript are available at <https://github.com/YanshengLuo/InnateImmuneResponseScore>. Public dataset accessions are listed in the repository materials and manuscript supplementary tables. Released derived inputs include frozen IMRS gene-weight tables, metadata/provenance summaries, split-level manuscript inputs, robustness summaries, retained-gene enrichment results, and reviewer-facing regeneration materials.

Raw sequencing files should generally be retrieved from public repositories by accession rather than redistributed, unless redistribution is explicitly allowed and practical. The repository distinguishes Layer 1 full computational provenance from gene counts and curated metadata/split definitions, including upstream public-data/HPC operations where applicable, from Layer 2 reviewer-facing manuscript-output reproduction using staged derived inputs.

No archival DOI has been assigned in this repository release candidate; an archival DOI may be added to the manuscript and repository metadata if one is issued in a future archival deposit.
